📘 Manual Científico

COMO PREENCHER:

• Tipo → formato do post (Reel, Carrossel, Story, Estático)
• Tema → conteúdo (IST, Prevenção, Educação)
• Curtidas → aprovação do conteúdo
• Comentários → engajamento profundo
• Compartilhamentos → potencial de viralização
• Salvos → valor educativo
• Alcance → base de cálculo

FÓRMULAS:

Engajamento (%) =
(curtidas + comentários + compartilhamentos + salvos) / alcance × 100

Desvio padrão =
medida de variação dos dados

Coeficiente de variação (CV) =
(desvio padrão / média) × 100

INTERPRETAÇÃO:

• CV < 20% → dados consistentes
• CV 20–30% → moderado
• CV > 30% → alta variabilidade

• Engajamento > 5% → excelente (saúde pública)
• Engajamento 2–5% → bom
• Engajamento < 2% → baixo desempenho

ANOVA:

• Compara desempenho entre tipos de post
• F alto → diferença significativa entre grupos
